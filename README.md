# Spiro-scan-Landing-page

Landing page interactiva y presentación de la solución para el proyecto **SpiroScan (TRL 4)** — *Sistema Embebido para Captura y Análisis de Señales Cardiorrespiratorias*.

## 🚀 Despliegue en Vercel

Este proyecto está listo para desplegarse como sitio web estático:

- **Framework Preset:** Other
- **Root Directory:** `./`
- **Build Command:** Ninguno (HTML puro con Tailwind CSS y FontAwesome vía CDN)
- **Output Directory:** `./`

## 📂 Contenido del Repositorio

- `index.html`: Landing page interactiva principal con narrativa técnica, interactivos de triaje y visualizador de arquitectura.
- `figuras_carcasa/`: Renders de diseño acústico, chasis y corte CAD.
- `DOCUMENTACION_PROYECTO_SPIROSCAN.md`: Memoria técnica del sistema y arquitectura.
- `RECOMENDACIONES_PRESENTACION_FERIA.md`: Guía de defensa para evaluadores de la feria.
